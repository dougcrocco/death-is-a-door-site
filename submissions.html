Submissions

Exhibition-documentation sites to send Death Is a Door to once the installation photos are in. Most use a web form, not email — the same pack covers them all.

+ How to use this page
  1. Get the photos first. Once the show is hung, have it photographed: wide room views, each wall, and every work in place. These sites publish installation views, so nothing goes out before that.
  2. Work through “Before you submit.” Tick each item as it’s done — closing date, photo credit, Vimeo link, and a Dropbox or Drive folder with the pack and photos (link set to never expire).
  3. Start with the pack. “Art Viewer - Death Is a Door” in Downloads has the press release, checklist and pre-filled form answers. Most of it copies straight into every form.
  4. Submit one site at a time. Click Open submission form, follow that site’s notes on the card (image sizes differ — Daily Lazy needs files under 2MB), then set the status to Submitted and add the date.
  5. Track replies. When a site publishes the show, set the status to Published and paste the link. No answer after two to three weeks? Mark it Declined / no reply.

Everything you change here saves for the whole team. Sign in with your name and the team password to edit.
